    Join the Conversation

    Have a question about GeoBlacklight or want to connect with other users and developers?

    • Join the Geo4Lib Slack and look for the #geoblacklight channel
    • Join the Geo4Lib Google Group to receive announcements and participate in discussions

    Contribute to the Software

    We welcome contributions from developers, metadata specialists, designers, and anyone interested in improving geospatial discovery.

    • Report an Issue

      Find a bug you want to report? Have an idea for a new feature? Anyone can create an issue in GeoBlacklight's GitHub repository for the community to address.

      Browse and submit issues

    • Contribute Code

      As open-source software, GeoBlacklight depends on contributions from our developer community. Anyone is welcome to code for review.

      Read our software contribution guide

    • Write Documentation

      Help keep our documentation up-to-date or fix information that is missing or unclear.

      Read our website contribution guide

    • Help Triage Issues

      Join our Issue Triage Group, where developers meet quarterly to review and prioritize GitHub issues. Reach out on Slack to join.

      Review our ongoing project board

    Join the Geo4Lib Community

    GeoBlacklight is part of the Geo4Lib Community, a community of practice for building tools, metadata, and platforms that improve access to geospatial resources in libraries. Visit geo4lib.org to:

    • Connect via communication channels
    • Find out how to join and participate in meetings, sprints, and conferences
    • Volunteer for a community role

    GeoBlacklight Project Maintainers

    Designated Code Mergers: GeoBlacklight Developers Team

    • Review pull requests
    • Assign individual code reviewers based on expertise

    Release Coordinators: Eric Larson + 1 vacancy

    • Cut tags and releases in the GitHub repository, and write release notes
    • Publish the GeoBlacklight Ruby gem
    • Publish Javascript to npm

    Technical Writing Lead: 1 vacancy

    • Keep track of code, metadata, and tutorials
    • Manage GitHub issues related to documentation
    • Coordinate volunteers to update documentation as needed
